# Metanoia

> **Learn deeply. Build consistently. Become useful. Create opportunities.**

Metanoia is my long-term Computer Science growth and career development project.

I am currently pursuing a **B.E. in Computer Science and Engineering with a specialization in Artificial Intelligence and Machine Learning**. This repository documents my journey from a university student with foundational programming knowledge to a capable software engineer and AI/ML practitioner.

The goal is not simply to collect code.

The goal is to build **real technical capability**.

---

## What is Metanoia?

**Metanoia** means a fundamental transformation in mindset, direction, and way of living.

This project represents my commitment to becoming more capable, disciplined, technically competent, and independent.

I want to build skills that allow me to:

- Understand Computer Science deeply
- Build useful software
- Solve real-world problems
- Develop strong technical foundations
- Create meaningful projects
- Build a portfolio backed by actual work
- Learn unfamiliar technologies independently
- Eventually earn through my technical skills

This is not a repository for random tutorial projects.

Everything here should represent some form of:

- Learning
- Experimentation
- Problem-solving
- Building
- Improvement
